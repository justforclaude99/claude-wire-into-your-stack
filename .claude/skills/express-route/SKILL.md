# Express Route Pattern

## Description

Use this skill when:
- creating a new Express route
- adding a new API endpoint
- creating route tests
- following the project's route structure

## Instructions

When creating routes:

1. Use Express Router.
2. Keep route handlers in `routes/`.
3. Return JSON responses.
4. Follow the existing code style.
5. When a route is added, create matching tests in `tests/`.
6. Match patterns already used in the project.
